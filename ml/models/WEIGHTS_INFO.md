(paper: https://arxiv.org/abs/2107.10833).

Only one top-level key, `params_ema` - 192 tensors, ~4.47M params. This is
the RRDBNet generator only (EMA-smoothed weights); Real-ESRGAN's public
releases never include the discriminator, since that's only used during
adversarial training and isn't needed for inference.

The load happens in `backend/app/superres.py` -
`load_state_dict(sd, strict=True)` against a 6-block RRDBNet, which already
matched every key exactly.
